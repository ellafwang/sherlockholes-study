## Session screen layout (from follow-up message)

- Session title at top; countdown timer directly beneath it (Teach stage only).

- Right-side icon-only buttons: question bubble = Q&A, treasure chest = Session Feedback.
- Back button top-left exits to the parent notebook.
- Q&A stage: same layout, timer hidden, one question at a time in a right-side "Q&A" box with its own back button (top-left of the box) returning to the Teach interface.
- Feedback stage: right-side "Feedback" box, notepad summary + lightbulb button to Learn from Sherlock, own back button top-left of the box.
- Bot persona: inquisitive, slightly confused student lacking context; asks "What is it?", "How does it work?", "What happens if [X] occurs?" when a concept is used undefined or explained poorly.
